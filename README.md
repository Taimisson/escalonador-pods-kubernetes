# Escalonador de PODs Kubernetes

Projeto do Trabalho I de Analise e Aplicacao de Sistemas Operacionais.

A proposta e implementar uma solucao inspirada no Kubernetes para escalonar PODs em
nodos Workers a partir de metricas computacionais, incluindo pelo menos uma metrica
alem de CPU e memoria.

## Estrutura

- `docs/`: enunciado e materiais de apoio.
- `src/`: codigo-fonte da solucao.
- `tests/`: testes, entradas e verificacoes.
