# Reports

Esta pasta recebe os arquivos gerados durante a execucao:

- `custom-decisions.jsonl`: decisoes do scheduler customizado.
- `custom-scheduler.log`: log coletado do Pod do Operator.
- `baseline-snapshot.json`: estado final da bateria com `default-scheduler`.
- `custom-snapshot.json`: estado final da bateria com `custom-scheduler`.

Os artefatos gerados sao ignorados pelo Git para manter o repositorio limpo.
